# Source Connect Global — photos the website needs

Every picture on the site is listed here, grouped by type, with where it shows, the size to aim for and a suggested file name. Tick each one when you have it.

**167 photos in total:** 144 product photos · 4 promo banners · 12 category pictures · 7 collection covers. The logo is already done.

## Photo rules (for every type)

| Rule | What to do |
|---|---|
| Format | JPG or WebP. PNG only when the background must be see-through (banner product cut-outs). |
| File size | Under 500 KB each. The admin panel shrinks uploads automatically, but smaller originals upload faster. |
| Background | Plain white or light grey for products, so the shop looks tidy. |
| Light | Daylight or a soft lamp, no harsh shadows, product fills about 80% of the picture. |
| Your own photos | Use photos you took or that the factory gave you permission to use. Do not copy pictures from other websites. |
| File names | Name each file with the ID in the tables below (for example `mens-1.jpg`), so it is easy to match. |

## How to add the photos

1. Open the admin panel → **Visual Editor**.
2. Point at the product, banner or category on the website preview and click **🖼 Change photo**.
3. For more photos of one product, click **✎ Edit** and use **Upload photos** (up to 8).

> **Storage note:** until the online database is connected, uploaded photos are saved in the browser, which holds about 5 MB (roughly 100 product photos). For all 144 products, use image links (paste a link in the product editor) or wait for the database step, which stores photos online.

_This list was generated from the demo catalogue. When you replace demo products with your own, the IDs change; the admin panel’s **Products → “No photo yet”** filter always shows what is still missing._
